Correlation (r) measures how strongly two quantitative variables move together in a straight line. It goes from −1 to 1. r = 0 means no LINEAR relationship, but there could still be a curve. Always plot the data first.

r has no units and doesn't change if you swap x and y. It's very sensitive to outliers.

Correlation doesn't prove causation. Reasons two things can be correlated without one causing the other:
- Lurking/confounding variable: ice cream sales and drowning both go up in summer. The cause is the heat.
- Reverse causation: does stress cause bad sleep, or does bad sleep cause stress?
- Coincidence: if you check enough pairs of variables, some will line up by accident (there's a website with charts like cheese consumption vs bedsheet deaths).

The only way to really show causation is a randomized controlled experiment, where random assignment balances out the confounders. Observational studies can only show association.

r² = the fraction of the variation in y explained by the line. r = 0.7 means r² = 0.49, so about half.
